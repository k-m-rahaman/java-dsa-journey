# 📖 Introduction

A **Graph** is a non-linear data structure consisting of **vertices (nodes)** and **edges** connecting them.

Graphs are widely used in navigation systems, social networks, computer networks, search engines, recommendation systems, and many interview problems.

Example

```
      A
     / \
    B---C
     \
      D
```
