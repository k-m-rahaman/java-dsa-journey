# 📖 Introduction

A **Heap** is a specialized complete binary tree that satisfies the **Heap Property**.

- **Min Heap:** The parent node is always smaller than or equal to its children.
- **Max Heap:** The parent node is always greater than or equal to its children.

Example

Max Heap

```
        50
      /    \
    40      30
   /  \    /  \
 20   10  15   5
```

Min Heap

```
        5
      /   \
    10     15
   /  \   /  \
 20  25 30   35
```
