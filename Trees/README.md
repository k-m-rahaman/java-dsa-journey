# 📖 Introduction

A **Tree** is a **non-linear data structure** that consists of **nodes** connected by **edges**.

Unlike arrays and linked lists, trees organize data hierarchically, making them useful for searching, sorting, databases, file systems, and many real-world applications.

Example

```
          10
         /  \
       20    30
      / \    / \
    40  50 60  70
```
